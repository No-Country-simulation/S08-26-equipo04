🗄️ QualityTrack - Diagrama Entidad-Relación (ER)

Estructura de Base de Datos y Relaciones

📌 Leyenda

🔑
PK (Primary Key): Clave Primaria - Identificador único
🔗
FK (Foreign Key): Clave Foránea - Referencia a otra tabla
Línea sólida 1:N: Un registro relacionado con Muchos
Línea sólida 1:1: Un registro relacionado con Uno
Línea punteada M:1: Muchos relacionados con Uno (USUARIO)
💡 Punto Importante: Las líneas con puntos indican que USUARIO aparece en múltiples lugares como "responsable", "operario" o "inspector". Una persona puede tener diferentes roles en diferentes operaciones.
