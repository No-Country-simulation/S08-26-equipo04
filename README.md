## 🌿 Flujo de Trabajo (Git Workflow)

Para mantener la calidad y consistencia del código, el equipo sigue una estrategia de branching basada en **GitFlow**:

- `main`: Código en producción o listo para entrega estable.
- `develop`: Rama principal de integración para el desarrollo activo.
- `feature/<nombre-tarea>`: Ramas secundarias para el desarrollo de funcionalidades específicas.
